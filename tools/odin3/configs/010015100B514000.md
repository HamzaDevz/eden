# Super Mario Bros. Wonder (010015100B514000), Odin 3

App officielle Eden v0.2.1 (`com.miHoYo.Yuanshen`), jeu en 1.0.1 (mise à jour appliquée), pilote Qualcomm système
512.800.72. Banc du 2026-10-16 : profil « Eden », niveau « Sauts et rythme » (Mont nébuleux), Luigi marche à droite
et à gauche (`MODE=walk`), 60 s. Séquence de démarrage propre au jeu : L+R au titre, puis A (profil), A (1 joueur),
A (personnage), A (OK), A sur le niveau du curseur.

## Config retenue

```
Renderer.use_asynchronous_gpu_emulation=true Cpu.cpu_backend=1 Renderer.force_max_clock=false
```

La chauffe venait de `force_max_clock=true` dans l'INI global : le mode Turbo garde le GPU à 1100 MHz et son thread
(sans nom, il hérite de « NativeEmulation ») tourne à 100 % dans le noyau sur un cœur prime.

## Mesures (60 s en niveau)

- INI d'origine (GPU synchrone, Dynarmic, Turbo) : 58,2 fps, 6,1 % sous 60, 27 chutes (la plus longue 833 ms),
  11,8 W (pointe 14,9), CPU 104,7 °C, GPU 81,4 °C.
- + GPU asynchrone + NCE : 60,0 fps, 0 chute, 10,8 W, CPU 103,9 °C, GPU 73,7 °C.
- + Turbo coupé (retenue) : 60,0 fps, 1 image à 25 ms, 3,8 W (pointe 7,0), CPU 59,7 °C, GPU 47,1 °C, GPU à 660 MHz
  et 18 % occupé. Aucun glitch visible sur les captures.
